# General Roman Calendar - fixed civil-date celebrations (universal/general calendar, Ordinary Form).
#
# This dataset is the single source of truth for every FIXED-date solemnity, feast, and memorial.
# Moveable (Easter-relative) celebrations and Sunday-based feasts of the Lord are computed in code,
# not listed here. Regional/national propers are intentionally out of scope.
#
# Format (pipe-delimited), one celebration per line:
#   MM-DD | Rank | Color | Name [| SaintSlug] [| Summary]
# Rank  : Solemnity | Feast | Memorial | OptionalMemorial
# Color : White | Red | Green | Violet | Rose
# SaintSlug : OPTIONAL fifth field linking the celebration to a saint profile at
#             discover/saints/{slug}. Add it only when a profile exists; omit it otherwise.
# Summary   : OPTIONAL sixth field, a short one-line description of the day. Author it for days with
#             no linked saint profile (e.g. feasts of the Lord, Marian days, mysteries) so the dialog
#             can still explain the day. When a SaintSlug is present the profile supplies the summary,
#             so this field is usually left empty for saint days. To set a Summary without a SaintSlug,
#             leave the fifth field empty: MM-DD | Rank | Color | Name |  | Summary
# We may need further adjustment to support multiple saints on the same day, such as Saints Basil the Great and Gregory Nazianzen.
# Though a different approach may need to be considered for items like 'Saints John de Brébeuf and Isaac Jogues, Priests, and Companions, Martyrs'.
# 'Saints Simon and Jude, Apostles' also presents a challenge.
# Lines beginning with '#' and blank lines are ignored. Several celebrations may share a date.
