Some things come to be and pass away &mdash; they are *contingent*, able either to exist
or not. If everything were like this, then at some point nothing would have existed, and
from nothing, nothing comes. So something would exist now by necessity.

1. Contingent things exist (they are generated and corrupted).
2. If all things were contingent, there was a time when nothing existed.
3. But then nothing would exist now, which is false.
4. So there must exist a being whose existence is necessary.
5. Necessary beings either have their necessity from another or not; this cannot regress
   infinitely, so there is a being necessary of itself &mdash; and this is God.
