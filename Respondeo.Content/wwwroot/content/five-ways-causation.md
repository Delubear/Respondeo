In the world we find an order of efficient causes. Nothing is the efficient cause of
itself, for it would have to exist prior to itself, which is impossible.

1. There is an order of efficient causes.
2. Nothing can be the efficient cause of itself.
3. An infinite regress of essentially ordered causes would remove the first cause, and
   with it every intermediate and final effect.
4. Therefore there is a first efficient cause &mdash; which everyone calls God.

The regress here is *essential*, not merely temporal: each cause depends here and now on
the one before it, like links holding a chandelier.
